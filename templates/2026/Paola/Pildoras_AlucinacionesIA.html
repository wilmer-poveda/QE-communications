Alucinaciones de la inteligencia artificial (IA)

¿Qué es una Alucinación de IA?

Es cuando un modelo de lenguaje (como un LLM) genera una respuesta que suena completamente convincente, lógica y coherente, pero que es fácticamente falsa o inventada.
En términos de QA, no es un error de código que rompe el sistema (un crash); es la IA fallando con una confianza absoluta. Nuestro reto ya no es buscar pantallas rotas, sino auditar la verdad.
Las alucinaciones no son fallos aleatorios, son una característica intrínseca de cómo funcionan los LLMs actuales. Un LLM es, esencialmente, una máquina de predicción probabilística de tokens (palabras o subpalabras). No es una base de datos de hechos, ni un motor de búsqueda que "entiende" la verdad objetiva.

¿Por qué suceden?

  • Naturaleza Generativa: El modelo está entrenado para maximizar la probabilidad de que la secuencia de texto parezca coherente y natural, no para que sea cierta. Ante una pregunta compleja, prioriza la fluidez narrativa sobre la precisión fáctica.
  • Confusión de Creatividad vs. Hecho: El modelo confunde los patrones creativos que aprendió durante el entrenamiento con datos duros. Cree que si una respuesta suena bien y sigue la estructura lógica correcta, debe ser correcta.
  • Falta de Anclaje: Sin acceso a información externa y actualizada (grounding), el modelo solo puede confiar en los pesos internos de su red neuronal, que son estáticos y pueden contener sesgos o datos incorrectos.



Este gráfico ilustra el concepto central: el "cerebro" de la IA procesando una pregunta histórica simple, pero en lugar de recuperar datos precisos, su motor creativo se dispara. La lógica interna se confunde (patrones abstractos) y genera una respuesta fluida pero completamente inventada: "Los romanos inventaron los hoverboards".

Por último, un tip para el proceso de QA podría ser diseñar un Dataset de "Golden Prompts" (Casos de Prueba Clave). Al igual que se tiene una suite de pruebas de regresión, crear un banco fijo de al menos 50-100 preguntas críticas para el negocio. Este dataset debe incluir deliberadamente:

Preguntas con trampa: Preguntas sobre temas que no están en la base de conocimiento para ver si la IA es capaz de decir "No lo sé" o si prefiere inventar una respuesta.
Casos de borde (Edge cases): Variaciones con sinónimos, modismos regionales, o errores ortográficos para evaluar si el sistema mantiene la fidelidad bajo presión.
